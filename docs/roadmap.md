# Roadmap

## Platform

- Reproducible local and Docker environments
- Strict static analysis and automated quality gates
- Health, OpenAPI, migrations, and API smoke tests

## API

- Activity resource and persistence
- Runtime validation and standardized errors
- Filtering, pagination, concurrency, and idempotency
- Multi-user authentication and authorization

## Delivery

- Public deployment and operational observability
- Web interface consuming the shared API contracts
